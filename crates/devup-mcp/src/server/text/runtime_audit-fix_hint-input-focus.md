A field's focus does not mark the box the user sees. Read measured.fields: for each field, `container` is the box that draws the border, `mode` is click or tab. If the field sits inside a bordered container (icon, prefix, button), put the focus style on the container with _focusWithin (borderColor plus a boxShadow ring from the theme) and remove only the field's own outline (_focus={{ outline: "none" }}) once the container shows it; never give the container tabIndex. If the field is its own box, put _focusVisible on the field. Keep the resting border width (change borderColor, draw extra width with boxShadow or outline) so nothing moves. If a reason says the focus state snaps, give the box that changes transition="160ms ease-out" with transitionProperty naming only the changed paint (border-color, box-shadow, background), or the prototype's duration and easing. Keep labels, aria-invalid error styles and _disabled. Re-run the input-focus check after the fix.
