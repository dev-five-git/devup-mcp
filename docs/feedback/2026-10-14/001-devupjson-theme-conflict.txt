[devup-mcp 개선 제안 #001] devupJson 출력이 DEVUP_THEME_CONFLICT 로 실패

일시: 2026-10-13
버전: devup-mcp 0.14.0 (commit b7018cd967ef), 브리지 경로
호출: devup_figma_export { frameIds: ["38:5207"], outputs: ["tsx", "devupJson"], projectRoot: apps/landing }
대상: Figma 파일 "프라임 by 데브파이브" (YVPOYYXZJpOayp0QlCdIVT), 메인 Desktop 프레임 38:5207

증상
- tsx 단독 호출은 성공(status=partial, projection=lossy).
- devupJson 을 함께 요청하면 projection-and-write 단계에서 실패.
  message: "Text style 'S:06c23fd3d6a7f685ce21a7adc165ccf09135c6e3,' needs a fixed
  numeric font size for an integer percentage line advance; variable or missing sizes
  are not representable."
- 텍스트 스타일 한 개가 문제인데 전체 devupJson 이 통째로 실패한다. 부분 결과가 없다.

원인 추정
- 글꼴 크기가 Figma 변수에 바인딩되어 있거나 비어 있는 텍스트 스타일에서 lineHeight 퍼센트 -> 정수 환산을 못 한다.
- 스타일 이름 자리에 스타일 ID(S:...,)가 그대로 노출되어 어떤 스타일인지 알 수 없다.

개선 제안
1. 실패한 스타일만 건너뛰고 나머지 토큰은 devupJson 으로 내보낸다.
   건너뛴 스타일은 warnings/projectionIssues 에 이름과 함께 나열한다.
2. 오류 메시지에 스타일 ID 대신 스타일 이름과 해당 노드 ID 를 넣는다.
3. 변수/미지정 글꼴 크기는 lineHeight 를 "140%" 같은 문자열 그대로 두는 폴백을 제공한다.
4. tsx 가 이미 쓰는 토큰($primary, typography="h1" 등)만으로 최소 devup.json 을 만드는
   outputs 옵션(예: devupJson: "used-only")을 둔다.
5. 이미 devup.json 이 있는 프로젝트는 tsx 가 요구하는 토큰 중 없는 것만 diff 로 돌려준다.

추천 프롬프트(에이전트용)
"devup_figma_export 의 devupJson 이 실패하면 tsx 만 받고, 사용된 $token 과 typography 이름을
 tsx 에서 추출해 devup.json 에 없는 항목만 추가해라. 이름 충돌은 프로젝트 기존 이름을 우선한다."
