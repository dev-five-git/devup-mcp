# R3 asset batches and projection evidence

Asset collection uses the same small-batch contract as frame collection: recommend 1–3 assetRequests, maximum 6. The schema and tool description advertise this before calls. Oversized calls fail before authentication, collection, or writes, with recommendedAssetRequests and remainingAssetRequests preserving format, scale and outputPath. Frame and asset limits apply independently; neither is a promise about elapsed time.

Asset requests start a server-local job. Fast completion keeps the ordinary export response and adds assetJob. Otherwise the caller receives status=in_progress, assetJob.jobId, stage, call progress, per-asset status, and a nextAction example. Poll devup_figma_export with {"jobId":"..."}. A paused job resumes with {"jobId":"...","jobAction":"resume"}. Do not resubmit the full batch to restart it. Resubmitting identical arguments recovers the existing job if its initial reply was lost.

A timed-out read budget (including pacing and upstream retries) pauses before the collector discards the pending call. Resume retries that read, preserving prior snapshot pages, binary chunks and asset results. A client timeout or cancellation does not cancel the job. Jobs live in this server process, not across server restart. Pending checkpoints expire after 30 minutes; completed results expire after 5 minutes (or the 30-minute overall deadline, whichever comes first). Up to 8 jobs are retained at once; capacity errors list existing IDs. Expired IDs return an explicit error. Ordinary non-retryable asset failures remain individual results. Binary export and disk delivery are separate: exported means validated bytes are retained; fileState=written is reported only after successful output delivery.

Placement approximation evidence includes original x/y/width/height, constraints, transforms, absoluteBoundingBox, sizing, padding, parent geometry and direct-child geometry. parentRelativeBounds states its coordinate basis; differences of absolute bounding boxes are axis-aligned offsets, not inverse-rotated local coordinates. Unknown fields stay null with a missing-source reason. derivedPadding is generator-computed evidence alongside source child positions, not a Figma padding value. Approximation does not become exact merely because evidence is richer.

Each projection issue carries details.output. Read outputResults.tsx, outputResults.componentTsx and outputResults.responsiveTsx separately. Aggregate quality.projection is the worst of produced projections, including opportunistic responsiveTsx when a tsx request contains multiple widths. It is not the fidelity grade of an individual output. For responsiveTsx, fidelity contains explicitly scoped breakpoint reports and merged unrepresented-content evidence; source coverage does not prove the merged module's responsive behavior.
