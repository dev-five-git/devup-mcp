# ChondroGen feedback coverage

Source: the 22 entries dated 2026-11-03 in ChondroGen's `docs/feedback.json`,
including their Korean requests, MCP acceptance criteria and subsequent user
corrections. Existing `resolved` statuses in that file describe the application
work; they do **not** establish that the reusable MCP behavior was implemented.
This report audits the combined MCP changes and does not change those records.

The [14 follow-up improvements](chondrogen-followup-14-coverage.md) add executable
shared controllers, measured motion/data checks, source-bound completion and
guarded source/asset migrations to the initial handoffs described below. They
also record the production App Router consumer and full browser CI gate.

`Implemented` below means an actual generator, delivery, validator or audit
capability. `Handoff` means shipped, executable-tool-delivered implementation
obligations that an agent must apply when building an application. A behavior
plan is never evidence that a static TSX export already animates or uses a live DB.

## Limits that remain visible

- Runtime motion controllers, application server layouts and live data bindings
  are intentional implementation handoffs. Their plans say `implemented: false`
  and `runtimeVerified: false`; this audit does not relabel them as generated
  functioning application code.
- Browser plans can assert selection and inspect appearance, but a route-tab
  animation still needs explicit DOM continuity/animation/intermediate-geometry
  assertions for the actual application. Footer checks need representative short,
  empty, long and tall-viewports, not only a single default dataset.
- Responsive wrapper reconciliation is conservative and reports unsafe or
  ambiguous structures. A derived contents wrapper is retained as unverified
  topology pending a real browser check, even when all child content is unified.
- Asset reuse is exact/proven-safe. Unsupported SVG semantics, approximate
  geometry, complex grayscale equivalence and raster crop/quality decisions stay
  distinct or explicitly unverified. There is no automatic deletion of arbitrary
  existing public files or a guessed DB migration.

The test names above identify concrete regression cases, not a declaration that
every case passed in this exact tree. Final validation logs and totals belong in
the PR; historical ChondroGen browser results are not substituted for MCP tests.
